Setup iPhone

Kunci HP sampai kuis pagi selesai

Gratis, memakai app Shortcuts bawaan iPhone. Setiap jam 06:00 kuis terbuka otomatis. Saat Anda membuka app pengalih perhatian (Instagram, TikTok, YouTube, dll.) sebelum kuis selesai, iPhone meminta kode buka. Kode hanya muncul setelah 10 soal terjawab.

Link aplikasi

Buka link ini di Safari dan login ke claude.ai sekali. Progres tersimpan di akun Anda, jadi sama di Safari maupun app Claude.

1. Pop-up otomatis setiap jam 06:00

Langkah paling penting, cukup 1 menit. Kuis terbuka sendiri di layar tanpa perlu diketuk.

  1. Buka app Shortcuts → tab Automation → + (atau New Automation).
  2. Pilih Time of Day → 06:00 → Repeat Daily.
  3. Pilih Run Immediately (bukan "Run After Confirmation") dan matikan Notify When Run. Ketuk Next.
  4. Pilih New Blank Automation → tambah aksi Open URLs → tempel link aplikasi di atas → Done.
  5. Uji: ubah sementara jam otomasi ke 2 menit dari sekarang, kunci HP, tunggu. Kuis harus terbuka sendiri. Kembalikan ke 06:00.

Agar pasti bangun: pasang juga alarm Clock jam 06:00. Otomasi ini membuka kuis tepat saat alarm berbunyi.

2. Buat shortcut "Gerbang Prep"

  1. Buka app Shortcuts → tab Shortcuts → +. Beri nama Gerbang Prep.
  2. Tambah aksi Get File (Dapatkan File): folder Shortcuts, path PrepMaster/selesai.txt. Matikan Error If Not Found.
  3. Tambah Get Text from Input dengan input File.
  4. Tambah Format Date: tanggal Current Date, Date Format Custom = yyyyMMdd, Time Format None.
  5. Tambah If: Text is Formatted Date → di dalamnya Stop This Shortcut. (Artinya: sudah buka hari ini, biarkan lewat.)
  6. Di bawah blok If (setelah End If), tambah tiga Calculate berurutan:
    Formatted Date × 37 → hasil + 4242 → hasil Modulus 9973.
  7. Tambah Ask for Input: tipe Number, pertanyaan Kode buka dari Prep Master?
  8. Tambah If: Provided Input is Calculation Result (hasil Modulus):
    – Then: Save File berisi Formatted Date ke Shortcuts/PrepMaster/selesai.txt dengan Overwrite menyala, lalu Show Notification Terbuka. Semangat!
    – Otherwise: Open URLs dengan link aplikasi di atas.

Kode hari ini: . Rumusnya sama dengan di Shortcuts: (tanggal yyyyMMdd × 37 + 4242) mod 9973. Pakai untuk menguji shortcut setelah dibuat.

3. Gerbang saat membuka app lain

  1. Automation → + → App → pilih app yang ingin dikunci (Instagram, TikTok, YouTube, X, WhatsApp, game). Centang Is Opened.
  2. Run Immediately, aksi: Run Shortcut → Gerbang Prep.
  3. Hasilnya: sebelum kuis selesai, setiap kali app itu dibuka Anda diminta kode; jika salah atau dibatalkan, iPhone langsung membuka kuis.

4. Opsional: kunci lebih ketat dengan Screen Time

  1. Settings → Screen Time → Downtime: Scheduled 06:00–06:45, Block at Downtime menyala.
  2. Always Allowed: Phone, Messages, Safari, Claude, Shortcuts.
  3. Minta orang lain mengetikkan Screen Time Passcode supaya Anda tidak bisa mematikannya sendiri.

Catatan jujur: tanpa app native, kunci ini bisa diakali dengan menghapus otomasi. Fungsinya sebagai pengingat disiplin yang kuat, bukan kunci mutlak.
